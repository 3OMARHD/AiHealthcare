Secure Medical Records
on the Blockchain

A decentralized system where doctors write tamper-proof records, patients own their data, and admins see only anonymized metadata — all verified on-chain.

🔒

Hash on Chain

Only the SHA-256 fingerprint of each record is stored on-chain — content stays private. Any tampering is instantly detectable.

👥

Role-Based Access

Doctors write and read their records. Patients access their own data. Admins see only anonymous metadata.

⛓️

Immutable Audit Trail

Every record creation emits a blockchain event — a permanent, tamper-proof audit log that cannot be deleted.
