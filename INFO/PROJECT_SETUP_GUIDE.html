1. Database Setup

1aStart XAMPP → Start MySQL

Open XAMPP Control Panel and click Start next to MySQL.

1bCreate Database

Open phpMyAdmin → Click New → Name: securedocs_db → Create.

1cImport Schema

In phpMyAdmin, select securedocs_db → Import tab → Choose file:

INFO\securedocs_db_complete.sql

Click Go. This creates all 13 tables with blockchain columns.

Alternatively via CLI: 
Get-Content "INFO\securedocs_db_complete.sql" | & "C:\xampp\mysql\bin\mysql.exe" -u root securedocs_db

5. Test: Patient Registration

5aRegister Patient
  1. Go to http://127.0.0.1:5000/register
  2. Fill in: Username, Email, Password, First/Last Name
  3. Role: Patient
  4. Wallet Address: 0x3C44CdDdB6a900fa2b585dd299e03d12FA4293BC (Account #2)
  5. Click Register
5bSetup 2FA
  1. After registration, you'll be asked to set up 2FA (TOTP)
  2. Scan the QR code with Google Authenticator / Authy
  3. Enter the 6-digit code to verify
5cLogin as Patient
  1. Go to /login → Enter credentials → Enter 2FA code
  2. ✓ Expected: Redirected to Patient Dashboard
  3. You should see: Dashboard stats, appointment booking, notifications

8. Test: Doctor Creates Record + MetaMask

8aSwitch MetaMask to Doctor Wallet

In MetaMask, switch to Account #1 (Doctor: 0x7099...79C8)

Critical! MetaMask must be on the doctor's wallet, NOT the patient's. This is the most common error.
8bAdd Medical Record
  1. On Doctor Dashboard → "Add Medical Record" form
  2. Select the Patient from dropdown
  3. Enter Diagnosis and Treatment
  4. Click "Sign & Anchor on Chain (MetaMask)"
8cMetaMask Confirmation Flow
  1. ✓ Status: "Saving & RSA-signing record in database..."
  2. ✓ Status: "Connecting to MetaMask..."
  3. ✓ MetaMask popup appears → Click Confirm
  4. ✓ Status: "Transaction submitted! Waiting..."
  5. ✓ Status: "Record signed & anchored on blockchain!" with TX hash

9. Test: Patient Views Record

9aView in UI
  1. Switch MetaMask to Account #2 (Patient)
  2. Login as Patient → Go to Medical Records
  3. ✓ Expected: Record shows with ⛓ On-Chain #1 badge
  4. Click the badge → Modal shows TX hash details
9bLoad from MetaMask
  1. Scroll to "My Blockchain Transactions" section
  2. Click "Load from MetaMask"
  3. ✓ Expected: Table shows record with Doctor wallet, diagnosis label, type, date, "✓ Verified"

11. System Architecture

┌─────────────┐     ┌──────────────┐     ┌─────────────────┐
│   Browser   │────▶│  Flask App   │────▶│  MySQL (XAMPP)   │
│  (MetaMask) │     │  :5000       │     │  securedocs_db   │
└──────┬──────┘     └──────┬───────┘     └─────────────────┘
       │                   │
       │  ethers.js        │  web3 (blockchain_utils.py)
       ▼                   ▼
┌──────────────────────────────────┐
│     Hardhat Local Blockchain     │
│     :8545  (Chain ID: 31337)     │
│                                  │
│  ┌────────────────────────────┐  │
│  │  MedicalRecords Contract   │  │
│  │  - registerDoctor()       │  │
│  │  - registerPatient()      │  │
│  │  - addRecord() ← MetaMask │  │
│  │  - getRecord()            │  │
│  │  - getPatientRecordIds()  │  │
│  │  - getAllRecordIds()       │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘

Data Flow (Doctor adds record):
  1. Doctor fills form → clicks "Sign & Anchor"
  2. Flask API: saves to MySQL + RSA signs
  3. Browser: MetaMask popup → doctor signs TX
  4. Blockchain: addRecord(patient, hash, label, type)
  5. Browser: updates MySQL with TX hash
  6. Patient: sees ⛓ On-Chain badge + can verify via MetaMask

All Tests Passed!

If all steps above show ✓, your system is fully operational with blockchain integration.
